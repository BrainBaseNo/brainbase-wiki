# Delingsmodell på BrainBase-plattformen
Gjeldende modell: konsulenten beholder 96 % av timeprisen. Totalt trekkes 4 %, fordelt slik som på [modellen vår](https://www.brainbase.no/modell).

### Beskrivelse av modellen
**Konsulenten beholder alltid 96 % av timeprisen.**

* **2 % plattformavgift:** drift og utvikling av plattformen.
* **2 % kickback til formidler:** konsulenter i nettverket som formidler oppdragene og hjelper med kommunikasjon, kontrakter og liknende.
